# Registro de uso de inteligencia artificial

## Como a IA foi utilizada

A inteligencia artificial foi utilizada como apoio para:

- comparar o projeto com os requisitos da atividade;
- identificar divergencias entre o codigo, o README e o relatorio;
- revisar a organizacao e a clareza dos textos;
- apoiar a depuracao das regras logicas e dos alertas;
- sugerir casos de teste para a crise das `20:00` e a inconsistencia das `23:00`.

## Validacao critica realizada

As sugestoes nao foram aceitas apenas por terem sido geradas por IA. O projeto foi validado por meio de:

- leitura direta dos requisitos da atividade;
- conferencia manual das regras implementadas no codigo;
- execucao completa do programa com os dados de `data/Dados.csv`;
- verificacao dos alertas, da previsao e das recomendacoes apresentadas;
- comparacao entre o comportamento real do sistema e a documentacao.

## Responsabilidade da equipe

A equipe deve revisar o codigo e a documentacao, compreender cada regra e ser capaz de explicar durante a apresentacao por que cada alerta e recomendacao sao gerados.
